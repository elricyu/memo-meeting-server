# 用户指南

1. 打开默认线上实例 [https://memo-meeting.easymr.cn](https://memo-meeting.easymr.cn)，注册并登录账号；自行部署时使用自己的服务地址。
2. 浏览器录音直接新建会议；眼镜录音先在「我的眼镜」生成二维码，眼镜通过语音扫码，网页核对设备并确认。
3. 开始后确认录音成功，再进行会议。网页可实时查看同账号的记录。
4. 停止后等待音频和尾句保存，再回听、生成纪要或导出 Markdown。
5. 纪要和转录可能出错，使用前核对人名、数字和关键结论。

音频会发送到本服务，转录与纪要内容会按管理员配置发送到外部 AI 服务；眼镜还会保存本地 WAV。请在录音前告知参会者，并向部署者了解数据保留与删除方式。

解绑使眼镜旧凭证失效，保留原账号历史会议。更换账号时先解绑再重新扫码。眼镜没有收到录音成功反馈、网络中断或出现失败提示时，不要将其视为仍在正常录音。
